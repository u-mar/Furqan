# Reciter photos

Drop a photo here named `<reciter-id>.jpg` and it appears automatically in Listen —
no code change needed. If the file is missing, the app falls back to a gradient
initials tile, so nothing breaks.

The ids come from `lib/reciters.ts`, for example:

- `alafasy.jpg` — Mishary Alafasy
- `sudais.jpg` — Abdur-Rahman As-Sudais
- `abdulbasit.jpg` — Abdul Basit Abdul Samad
- `minshawi.jpg` — Mohamed Siddiq Al-Minshawi
- `husary.jpg` — Mahmoud Al-Husary
- `maher.jpg` — Maher Al-Muaiqly
- `shuraim.jpg` — Saud Al-Shuraim
- `ajmi.jpg` — Ahmad Al-Ajmi
- `yasser_dosari.jpg` — Yasser Al-Dosari
- `ghamadi.jpg` — Saad Al-Ghamdi

Square images work best (roughly 256×256 or larger). Only use photos you have the
rights to distribute.
